# Обзор проекта

## Что это

EasyTerms — **self-hosted** Telegram-бот, который помогает понять онлайн-соглашения до нажатия Accept. Пользователь отправляет ссылку или текст; бот объясняет соглашение простым языком и подсвечивает рискованные пункты.

Фокус: Terms of Use, Privacy Policy, EULA, cookie- и consent-тексты. **Не юридическая консультация** — только информационная помощь.

## Для кого

- **Self-hosters** — один инстанс на свой сервер или локально
- Обычные пользователи интернета, которые хотят быстро разобраться в соглашении перед регистрацией

## Проблема

Юридические соглашения длинные и написаны канцеляритом. Большинство людей их не читают и соглашаются с тем, чего не понимают.

## Ценность

- Объяснение простым языком
- Подсветка важных пунктов (приватность, платежи, ответственность, удаление аккаунта)
- Быстрое осознанное решение без чтения полного текста

## Текущий статус

- **Open-source personal bot** (MIT), без монетизации и платёжной логики
- Стек: Go, **SQLite**, Telegram через go-telegram/bot, LLM через OpenAI-compatible API
- Ограничение доступа: `ALLOWED_TELEGRAM_IDS` (пусто = публичный бот с warning в логах)
- CI: `go test ./...` + Docker build на GitHub Actions
- Документация: `README.md` (EN), `README.ru.md` (RU), `.docs/`
